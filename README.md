# 🏠 北京/上海 房产智能助手

二手房交易全能工具，覆盖**税费计算、风险提醒、经纪人题库、房源推荐**四大核心场景。

**技术栈：** Python + Streamlit · 单文件部署 · 无需数据库 · 政策数据硬编码离线可用

[![Streamlit](https://img.shields.io/badge/Streamlit-1.57+-FF4B4B?logo=streamlit)](https://streamlit.io)
[![Python](https://img.shields.io/badge/Python-3.12+-3776AB?logo=python)](https://python.org)

---

## 🚀 快速启动

```bash
pip install streamlit
streamlit run house_app.py
```

浏览器访问 `http://localhost:8501` 即可使用。

## 📦 四大模块

### 💰 1. 税费计算器

输入房屋信息，自动计算全部税费并生成首付&贷款建议。

| 功能 | 说明 |
|------|------|
| 契税 | 首套二套 × 面积 × 城市差异自动判定 |
| 增值税 | 北京满2年免 / 上海满5年免 |
| 个人所得税 | 满五唯一自动识别免征 |
| 中介费 | 北京2.7% / 上海3% |
| 土地出让金 | 商品房 / 已购公房 / 经适房分别计算 |
| 税费柱状图 | 可视化各税种占比 |
| 首付贷款 | 北京二套60% / 上海二套50% |

**决策链：** 城市→总价→面积→房龄→买方套数→卖方状态→房屋性质，7步条件分支 → 5类税费 + 首付贷款汇总

### ⚠️ 2. 交易风险提醒

基于真实判例总结的 **12 大风险检查清单** + 三阶段操作指南。

| 风险等级 | 风险项 |
|----------|--------|
| 🔴 极高 | 查封风险、抵押风险、共有产权风险 |
| 🟡 高 | 户口迁移、学区占用、税费模糊、定金陷阱 |
| 🟠 中 | 面积误差、凶宅事件、违建私改、租赁先行、连环买卖 |

**增值功能：**
- 输入**房产证号**→ 自动解析京沪新旧版编码规则，生成核对清单
- 输入**卖方身份证号**→ 生成身份核验7步操作指引
- 输入房屋地址→ 自动生成个性化风险提醒总结（含建议合同条款）
- 三阶段操作指南：签约前 → 签约时 → 交房时
- 引用《民法典》相关法条

### 📝 3. 经纪人题库

基于 **2025年房地产经纪人职业资格考试** 四科大纲出题。

| 科目 | 题量 |
|------|------|
| 房地产交易制度政策 | 5题 |
| 房地产经纪职业导论 | 5题 |
| 房地产经纪专业基础 | 5题 |
| 房地产经纪业务操作 | 5题 |

**特色功能：**
- 🎲 **随机出题** — 每次进入或点击「换一批」打乱顺序，避免死记顺序
- 🎵 **顺口溜记忆法** — 20 题全配押韵口诀，答错自动展示，如：
  - *「北京二年就免征，上海五年才放行」*
  - *「签约之前拉产调，查封抵押全知道」*
  - *「套内除以建筑面，得房率高住得宽」*
- 📊 **分科评分** — 四科分别统计正确率，定位薄弱科目
- 📖 **逐题解析** — 每道题附详细法规/原理说明
- 🎯 两种模式：模拟考试（20题100分） / 单科练习

### 🏘️ 4. 房源片区推荐

覆盖 **北京10区 + 上海12区**，5 维度量化评分推荐。

| 维度 | 评分范围 | 数据项 |
|------|----------|--------|
| 🏫 学区 | 0-10 | 对口名校、教育质量 |
| 🚇 交通 | 0-10 | 地铁线路、通勤时间 |
| 🏥 医疗 | 0-10 | 三甲医院数量 |
| 🌳 公园 | 0-10 | 公园绿地、生态环境 |
| 🛍️ 购物 | 0-10 | 商圈配套 |

**推荐逻辑：**
- 5 个可拖动权重滑块（0-5），自定义各维度重要性
- 预算单价匹配 + 多维加权打分 + 通勤关键词匹配 + 片区偏好加分
- 结果展示：五维进度条雷达图、详细配套列表、匹配理由说明
- 附带看房5步建议 + 城市购房政策提醒（限购/社保/普宅认定）

## 🔧 技术特点

- **零依赖部署** — 仅需 `pip install streamlit`，无需数据库、无需后端
- **数据硬编码** — 所有政策数据内置在代码中，离线可用，按最新政策修改即可
- **单文件架构** — 全部逻辑在一个 `.py` 文件中，清晰分区，中文注释
- **Streamlit 原生** — 利用表单、列布局、侧边栏、进度条、柱状图等原生组件
- **隐私安全** — 风险模块输入信息仅在本地浏览器处理，不上传不存储
- **响应式布局** — 适配桌面/平板，`wide` 模式最大化利用屏幕空间
